# Древний Египет — интерактивный объяснятор для 5 класса

По учебнику: В. Р. Мединский, А. О. Чубарьян. «История. История Древнего мира. 5 класс», глава «Древний Египет» (§ 5–10).

## Файлы

- `index.html` — стартовая страница.
- `egypt-5-klass.html` — сам объяснятор: 10 интерактивных вопросов и раздел «Узнать больше».
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий (или папку в существующем) и загрузите все файлы из этой папки, включая `.nojekyll`.
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

Ссылка на конкретный вопрос: `egypt-5-klass.html#5` (номер вопроса после `#`).

## Технически

- Один HTML-файл без сборки и без библиотек. Шрифты (Bitter, Golos Text, Noto Sans Egyptian Hieroglyphs) грузятся с Google Fonts; без интернета страница работает с системными шрифтами (на Windows иероглифы показывает Segoe UI Historic).
- Страница ничего не сохраняет и никуда не отправляет.
- Работает на компьютере, проекторе и телефоне.
